C++ 对拍器

轻轻松松对拍 C++：生成器 → 可选 validator → 暴力 → 正解 → 普通比较 / 可选 Special Judge。 默认使用 Compiler Explorer 在线执行，无需填写 API 地址；打开页面、放进代码就能跑。
☁️ 正在连接在线编译器…
C++98 / 03 / 11 / 14 / 17 / 20 / 23 / 26 与对应 GNU++ 方言都可选；最终参数形如 -std=gnu++20 -O2 ...。 GCC 版本会从 Compiler Explorer 自动读取；若网络暂时不可用，会使用内置常用版本。旧 GCC 选择较新的 C++ 标准时，可能正常产生编译错误。
☁️ 在线执行后端 无需配置
默认使用 Compiler Explorer 执行 C++。这里没有 API 地址要填。 如果编译器列表没有刷新出来，可以点右侧按钮重新连接。时间/空间限制会在运行代码中注入 Linux 资源限制。
数据生成器必需 · stdout 作为测试输入 · argv[1] = seed
暴力程序必需 · stdin 为测试数据
正解程序必需 · stdin 为测试数据
数据合法性验证器可选 · 返回 0 表示合法，非 0 表示丢弃该数据
Special Judge可选 · 返回 0 表示接受，非 0 表示暴力与正解不等价
SPJ stdin 协议 
第一行：inputBytes bruteBytes solutionBytes
随后紧接三段原始字节：
[测试输入][暴力输出][正解输出]

建议读取方式：
size_t a, b, c; cin >> a >> b >> c; cin.get();
string input(a, '\0'), brute(b, '\0'), solution(c, '\0');
cin.read(input.data(), a); cin.read(brute.data(), b); cin.read(solution.data(), c);

return 0;  // 接受
return 1;  // 判错

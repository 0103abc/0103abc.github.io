这是一道非常基础的输入输出题，读入两个整数并输出它们的和。

## 思路

直接读入两个整数 `a` 和 `b`，输出 `a + b`。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

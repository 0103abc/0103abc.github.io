前置知识：Floyd 判环，分段打表

看到题目中给出的这个奇怪的线性递推式就可以猜测没有什么简单的性质可以入手了，因此容易想到去打表求循环节长度。直接用 umap 存所有出现过的数肯定是不行的，于是考虑使用 Floyd 判环，在 $O(1)$ 的空间复杂度内求得循环节长度为 $182129209$，在第 $350125310$ 位开始进入循环节。

这里简要的介绍一下 [Floyd 判环算法](https://zh.wikipedia.org/wiki/Floyd%E5%88%A4%E5%9C%88%E7%AE%97%E6%B3%95)（这个好像挺冷门的）：考虑维护两个指针 $p_1,p_2$，初始两个指针都指向 $F_0$。

第一步让指针 $p_1$ 每次从 $F_i$ 移动到 $F_{i+1}$，让指针 $p_2$ 每次从 $F_i$ 移动到 $F_{i+2}$，直到 $F_{p_1}=F_{p_2}$ 为止。

然后让 $p_1$ 指针回到 $F_0$ 位置，然后每次操作让 $p_1$ 每次从 $F_i$ 移动到 $F_{i+1}$，让 $p_2$ 每次从 $F_i$ 移动到 $F_{i+1}$，直到 $F_{p_1}=F_{p_2}$ 为止。

最后只移动 $p_2$ 指针，直到 $F_{p_1}=F_{p_2}$ 条件再次成立为止。容易证明最后一步 $p_2$ 指针移动的次数就是循环节的最小长度。

:::success[打表代码]
```cpp line-numbers
namespace Loyalty
{
    inline void init() {}
    inline int solve(int x) { return (x + (x >> 20) + 12345) % (1ll << 40); }
    inline void main([[maybe_unused]] int _ca, [[maybe_unused]] int _atc)
    {
        const int S0 = 0x600DCAFE;
        int p1 = S0, p2 = S0;
        do { p1 = solve(p1), p2 = solve(solve(p2)); } while (p1 != p2);
        p1 = S0; do { p1 = solve(p1), p2 = solve(p2); } while (p1 != p2);
        int cnt = 0; do { p2 = solve(p2), ++cnt; } while (p1 != p2);
        cout << "QwQ " << cnt << '\n'; cnt = 0;
        p1 = S0; while (p1 != p2) { ++cnt, p1 = solve(p1); }
        cout << "AwA " << cnt << '\n';
    }
} // namespace Loyalty
```

然后注意到这个 $F$ 序列是一直不变的，所以考虑直接 $O(1)$ 处理完整循环节部分，然后对序列进入循环节之前的开头部分和不完整的循环节前缀求和部分直接分段打表处理，然后做完了。

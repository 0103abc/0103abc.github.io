# 城市揭棋

## 城市与 2025 数据

城市名及地级区划代码取自 modood/Administrative-divisions-of-China 的 dist/cities.json（2026-11-14 下载），许可 WTFPL v2，原许可见 CITIES-LICENSE.txt。只采集地级市，排除直辖市、港澳台、县级市、林区、自治州、地区。293 个地级市中，三沙未找到 2025 GDP，明确排除，游戏池实际为 292 城。每局随机抽取 288 城，不重复。

2025 GDP 主数据来自鸥维公开排行榜 https://www.oweidata.com/rank/gdp/city?page=1 至 page=7（2026-11-15 获取），逐行校验 year=2025、与城市名精确连接，288 城。另补邢台、吉林、三亚、儋州共四城，逐条 URL 随 cities.json 保存；吉林、三亚、儋州来自政府发布，邢台为市统计局公报的公开转载。没有采用三沙估计值或较早年份冒充 2025。GDP 单位亿元。汇编数据未逐一复核全部官方公报，引用以各市公报最终核实值为准。

2025 年常住人口来自聚汇公开城市排名 https://m.gotohui.com/ranking/renkou/city ，200 条可见记录中筛选 2025 年后精确连接，游戏池覆盖 178 城，单位万人。未收录的城市显示缺失，不补零、不估算、不给人口分。人口和面积都未完整覆盖同年全体样本，统一不参与评分。

## 评分

GDP 分 = 10 + 90 × (ln(GDP) − ln(292 城最小 GDP)) / (ln(292 城最大 GDP) − ln(292 城最小 GDP))。

城市地位为明确行政类别：副省级省会 100、计划单列市 90、普通省会或自治区首府 80、普通地级市 30。类别名单参考武汉市发展和改革委员会资料 https://fgw.wuhan.gov.cn/xwzx/mtgz/202001/t20200116_864672.html 和清华大学省会城市／自治区首府名单 https://www.sppm.tsinghua.edu.cn/__local/5/E4/AA/C7740295314A7E69496ACBE6039_BCBAC39D_60C814.pdf 。这些分值和权重为游戏规则，不是官方排名。

最终强度 = 四舍五入(GDP 分 × 80% + 城市地位分 × 20%)。同分同归于尽。每城的原值、类别、分项与来源保存在数据文件中；对局界面不展示评分或数据表。评分版本 2025-gdp80-status20-v1。

## 规则与策略

每次进入或随机新局使用随机种子，重新抽取 288 个城市；双方各144枚，配对分配使总分接近，随机摆放，中心一格为空。「重开本盘」复用当前种子、不恢复已用悔棋；刷新为新局，不持久化对局。每局一次整回合悔棋。

AI 只接收公开观察，暗子无城市、阵营或分数字段。五档不同的随机失误率、收益与避险判断和有限宽度三层搜索，均非最优策略；策略在本地 Web Worker 中运行，失败时使用简单合法行动，15秒超时兜底。不接任何外部模型服务。
